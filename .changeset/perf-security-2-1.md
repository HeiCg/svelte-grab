feat: performance and memory tools for agents.

- Opt-in CDP mode (`svelte-grab-mcp --cdp=http://127.0.0.1:9222` or `SVELTE_GRAB_CDP`, loopback only, off by default; requires Node 22): `ui_perf_metrics` (Chrome counters around an action) and `ui_leak_check` (open/close cycles with forced GC, retained detached elements grouped by component and file:line). Without CDP, `ui_leak_check` runs page-side tracking and reports `INCONCLUSIVE`.
- `ui_network`: what a screen loads (fetch, XHR, sendBeacon, WebSocket, EventSource and resource timing), with the initiating file:line and component, totals, first- vs third-party, duplicates, slowest and failed requests; `reload: true` measures the initial load.
- `ui_security_scan`: runtime checks for credentials in URLs and in requests to third parties, tokens in Web Storage, JS-readable auth cookies, sensitive fields in SvelteKit page data, secret-shaped `VITE_` values, security headers, external links and mixed content. Secrets are always redacted (`kind:abcd…(len N, sha xxxxxx)`).
- Agent skills shipped in the package (`skills/`): `svelte-grab` (the `ui_*` loop) and `svelte-grab-audit` (per-screen security and performance audit with `CHECKLIST.md`, `REPORT-TEMPLATE.md` and `finding-schema.json`). `svelte-grab init` copies them into `.claude/skills/` by default (`--no-skills`, `--skills-dir <dir>`, `--force-skills`; edited files get a `<file>.new`; one-time pointer in an existing `AGENTS.md`), new `svelte-grab skills install|list|path`, the `sv` add-on installs them (`skills` option), and the MCP server exposes them as prompts (`svelte-grab-loop`, `security-audit`, `performance-audit`). The repo is also a Claude Code plugin marketplace (`.claude-plugin/`).
- `svelte-grab audit`: zero-config static security scanner for Svelte/SvelteKit (`{@html}` with dynamic input, secrets in client-reachable code and `PUBLIC_`/`VITE_` env, over-exposed `load` data, actions/remote commands without an auth check, `csrf.trustedOrigins: ['*']`, missing CSP, `postMessage` without origin check, `eval`, unsafe `target=_blank`, optional `--deps` advisories). Text, JSON (schema-validated) and single-file HTML reports; `--ci` exits 1 on confirmed findings at or above `--min-severity`.
